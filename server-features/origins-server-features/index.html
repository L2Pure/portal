Полезные голосовые команды (.commands)

Быстрое управление персонажем прямо из чата

In-Game Commands
.menu / .cfg Главная панель персонажа: автолут, блокировка опыта, анимация и безопасность
.autoloot Быстрое включение и выключение автоматического подбора предметов
.offline Посадка персонажа на оффлайн-торговлю или оффлайн-крафт (1 CoL)
.visual Менеджер DressMe для изменения визуального облика брони и оружия
.stats Подробная боевая статистика персонажа и текущих характеристик
.blockbuff Режим блокировки нежелательных баффов от других игроков
.sellbuff Создание персональной лавки продажи баффов в мирной зоне
.enchant Быстрый удобный интерфейс модификации экипировки
.lock Защита аккаунта: привязка персонажа по IP-адресу или HWID компьютера
.relog Мгновенный перезаход в мир без закрытия игрового клиента
.promocode Активация бонусных промокодов от администрации проекта
.repair Восстановление застрявшего персонажа на этом же аккаунте
